# Felipe Mendes Smargiassi

Brazilian criminal defense lawyer, registered with the Brazilian Bar Association, Minas Gerais Section (OAB/MG 155.242), since 2014. Based in Guaxupé, Minas Gerais, and taking cases throughout Brazil.

- Jury trials, arrests and custody hearings, criminal proceedings and sentence execution
- Written assistance for foreigners and families abroad whose relative is detained, missing or facing a case in Brazil
- Inheritance, property and divorce matters involving foreigners
- Open data: Brazilian judicial districts, courthouses and prison units by municipality (CC BY 4.0)
